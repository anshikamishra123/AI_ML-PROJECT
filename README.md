🧠 AI-Powered Disease Prediction App
A beginner-friendly machine learning web app built using Streamlit to predict Diabetes, Heart Disease, or Breast Cancer based on user inputs. This project demonstrates end-to-end ML — from training models to deploying a user-facing interface.

💡 Overview
This app uses:

Logistic Regression for Diabetes and Breast Cancer
Random Forest Classifier for Heart Disease
StandardScaler for feature scaling
Streamlit for a clean UI and interaction
Joblib for saving/loading trained models
🏥 Supported Predictions
Disease	Model	Dataset Source
Diabetes	Logistic Regression	Pima Indians Diabetes Database
Heart Disease	Random Forest	UCI Heart Disease Dataset
Breast Cancer	Logistic Regression	Sklearn's built-in Breast Cancer dataset
